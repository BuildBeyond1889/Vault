# Changelog

## 1.0 · October 2026

The first public release.

- **Downloaders:** one double-click file per subject (core knowledge, health, farming / water / energy / survival, repair and electronics, coding, learning, kids, maps, shelters and soup kitchens), a pocket set for phones and SD cards, Choose Packs for one-by-one picks, and Check for Updates. Downloads resume if the connection drops.
- **Licences:** 181 packs checked; the Get files only download the ones that are legal to share, and PACK-LICENSES.md travels with every copy.
- **Vault Search:** one search box over every pack (titles first, then full text), subject shelves, kids / teens / adults shelves, a random page and three picks a day, each pack's own front page with related packs.
- **Eight languages** on screen: English, Kiswahili, Français, Español, Português, العربية, हिन्दी, 中文 (drafts marked as drafts).
- **Sharing:** Make a Vault Drive (USB or SD card) and Make a Vault Zip.
- **Vault Search.exe** built by GitHub on every release, so nobody needs Python.
