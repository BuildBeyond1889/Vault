ARCHIE VAULT POCKET SET - an offline library for a phone, SD card or old computer

Phone (Android): install the free Kiwix app (Play Store, or the APK from kiwix.org copied over by USB).
Put this card in, open Kiwix, and it finds the .zim files in the zim folder.

Old computer: install Kiwix Desktop (kiwix.org) and open the .zim files, or copy Archie Vault onto it.

Every pack on this card may be shared for free. PACK-LICENSES.md lists each one's licence and the
credit it asks for. Keep that file with the card, and never sell or charge for copies.
