VAULT DRIVE - a free offline library

On a Windows computer: double-click "Vault Search.exe". A search page opens in your web browser.
Type what you want to know. Nothing needs the internet. Keep the black window open while you read.

On an Android phone: install the free Kiwix app (Play Store, or the APK from kiwix.org), then open
the .zim files in the zim folder.

This is a library, not a doctor, engineer or teacher. Pages can be out of date. When something is
urgent or dangerous, reach someone trained if you can.

Everything on this drive may be shared for free. PACK-LICENSES.md lists each collection's licence and
the credit it asks for. Keep it with the drive, and never sell or charge for copies.
Project page: https://github.com/BuildBeyond1889/vault
